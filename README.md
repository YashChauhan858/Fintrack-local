# Local AI Financial Analyzer

An AI-powered finance application that runs completely on your local machine. Upload your bank statements and get detailed financial analysis, smart insights, and beautiful visual charts — fully offline and privacy-first.

## Features

- AI-powered bank statement analysis
- Automatic income & expense calculation
- Net savings and cash flow tracking
- Savings rate analysis
- Average daily spending & income metrics
- Highest expense and income detection
- Zero spend day tracking
- Daily spending percentage insights
- Merchant-wise spending analysis
- Top 5 & Top 10 spending categories
- Tagged income & expense categorization
- Interactive charts and dashboards
- CSV / XLSX bank statement support
- 100% local AI processing
- Offline & privacy-focused

## Analytics Included

- Total Income
- Total Expenses
- Net Savings
- Net Cash Flow
- Savings Rate
- Daily Spending Trends
- Income Trends
- Top Merchant Spending
- Tagged Expense Breakdown
- Tagged Income Breakdown
- Financial Health Insights

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Chart.js
- Ollama (Local AI)

## Local AI Setup

- Install ollama

```bash
ollama start
```
